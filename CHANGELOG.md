---
Initial release for Minecraft 1.21.1 / NeoForge 21.1.
- Elixir flask, Essence Stones, Tinctures, Catalysts and the Athanor brewing station
- Ten default stones, four tinctures and four catalysts, all datapack-driven and overridable
- Global elixir cooldown with per-ingredient modifiers
- Server config for break chance, cooldown, capacity and stones per flask
- `/alchemical clearcooldown <player>` admin command
- Fix Bastion Stone recipe not loading (used the old `scute` item id instead of `turtle_scute`)
